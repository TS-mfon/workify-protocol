LOCKED REQUIREMENTS
1. leave tokens of eight characters or fewer unchanged
2. preserve the first four characters
3. preserve the final four characters
4. redact every middle character

IMPLEMENTATION (JavaScript)
```js
export function redactToken(input) {
  const token = String(input);
  if (token.length <= 8) return token;
  return token.slice(0, 4) + "*".repeat(token.length - 8) + token.slice(-4);
}
```
